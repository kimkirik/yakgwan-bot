# 약관돋보기 · 우리 가족 보험봇

**유료 API, API 키, 서버 업로드 없이** 가족별 보험 약관 PDF를 관리하고 근거 조항을 확인하는 한국어 웹앱입니다.

- 사용 주소: https://yakgwan-family.kimkirik.chatgpt.site
- 소스: https://github.com/kimkirik/yakgwan-bot

## 할 수 있는 일

- 이름/별명과 관계로 가족 명단 추가·수정·삭제
- 가족별 여러 약관 저장, 선택한 가족/문서만 대상으로 질문
- 보장·면책·한도·청구에 관련된 원문 발췌와 PDF 페이지 확인
- 원문 PDF 미리보기, 페이지 이동, 원본 다운로드
- 브라우저 IndexedDB에 가족·PDF·대화를 저장하고 새로고침 후 복원
- 글자가 없는 스캔 PDF에 한국어/영어 OCR 적용 (선택, 파일당 최대 50페이지)
- WebGPU 지원 기기의 무료 소형 AI 설명 (선택, Qwen3 0.6B / WebLLM)
- 모바일 가족/질문/근거 탭, 키보드 사용, 한글 조합 입력 지원

**기본 답변은 검색 기반 원문 발췌입니다.** 자유로운 생성형 설명은 사용자가 무료 AI를 켠 뒤 제공됩니다. 약관의 의미와 실제 보험금 지급을 확정하는 전문 서비스가 아닙니다. 근거를 못 찾았다는 것은 미보장 판정을 뜻하지 않습니다. 실제 가입 특약, 가입금액, 계약일은 보험증권과 보험사에서 확인하세요.

## 무료와 개인정보

API 사용료, 계정, 결제, 서버 추론은 없습니다. AI는 처음에 수백 MB의 모델을 Hugging Face에서 내려받고 이후 기기에서 실행합니다. OCR 첫 실행에는 공개 언어 파일을 내려받습니다. 인터넷 연결 비용은 통신 요금제에 따릅니다. 모델 다운로드 서버에 PDF나 질문을 보내지 않습니다. 운영 호스트의 보안 검사는 접속 정보를 처리할 수 있으며, 앱의 PDF/질문 처리와는 별개입니다.

가족 명단, PDF 원본, 추출한 텍스트, 대화는 **현재 기기·현재 브라우저**에 저장됩니다. 암호화된 계정 금고나 기기 간 동기화가 아닙니다. 공용 기기에서 사용하면 같은 브라우저 사용자도 자료를 볼 수 있습니다. 브라우저 데이터 삭제/시크릿 모드 종료/저장 공간 정리 시 자료가 없어질 수 있으므로 원본은 따로 보관하세요. 가족 삭제 시 연결 문서와 대화도 지우고, 문서 삭제 시 그 문서를 인용한 대화도 함께 지웁니다.

GitHub는 소스 백업과 검증에만 사용합니다. 운영 주소와 개인정보 저장은 GitHub Pages, GitHub Actions, raw GitHub 파일에 의존하지 않습니다. AI WASM 라이브러리는 빌드 시 내려받아 같은 운영 도메인에서 제공합니다.

## 로컬 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run prepare:assets
npm run dev
```

배포용 파일:

```sh
npm test
npm run build
npm run preview
```

`dist/`를 무료 정적 호스팅의 루트 경로에 올릴 수 있습니다. 자체 서버나 Mac mini를 공개 서버로 실행할 필요가 없습니다. PDF/OCR/WebLLM 런타임 자산이 포함되어 배포 파일은 약 70MB입니다. `public/vendor`와 `public/models`는 패키지/공개 모델에서 생성하는 자산이므로 소스 저장소에서는 제외합니다.

## 검증

```sh
npm test
npx playwright install chromium
npm run test:e2e
# 운영 주소에서 동일한 기능 확인:
TEST_URL=https://yakgwan-family.kimkirik.chatgpt.site npm run test:e2e
```

단위 테스트는 근거 검색, 근거 없음, 후속 질문, 가족 자료 분리, 문서·가족 삭제를 확인합니다. 브라우저 테스트는 실제 PDF 파싱, 원문 페이지 표시, 저장 복원, 가족 추가·수정·삭제, 잘못된 파일·중복 처리, 360/390px 모바일 화면을 확인합니다. 테스트의 문서와 이름은 모두 가상 데이터입니다.

## 제한

- 파일당 20MB / 500페이지, 전체 약관 50개, 가족 30명, 최근 대화 최대 200개
- OCR은 파일당 글자가 없는 페이지 최대 50개. 인식하지 못한 페이지를 경고합니다. 복잡한 표와 작은 글씨는 원문 대조가 필요합니다.
- 일부 텍스트가 있는 이미지 혼합 페이지는 자동 OCR 대상으로 탐지되지 않을 수 있습니다.
- 암호 PDF는 암호를 해제한 사본이 필요합니다.
- 검색 결과는 관련 일부 조항입니다. 모든 특약/주석/정의의 완전한 해석을 보장하지 않습니다.
- 가벼운 한국어 키워드·동의어 검색이므로 어려운 질문은 담보명을 명시해 다시 물어보세요.
- 문자 인식 결과를 바탕으로 한 AI 설명은 오인식 확대를 막기 위해 생략합니다. 소형 AI는 부정확할 수 있습니다. 원문과 금액·기간·면책 조건을 대조하세요. WebGPU/메모리가 부족하면 기본 원문 모드를 사용하세요.
- 인터넷 전체 검색, 보험 추천·판매·가입, 자동 보험금 산정, 가족 간 동기화는 포함하지 않습니다.

## 구성과 공개 라이브러리

TypeScript, Vite, PDF.js (Apache-2.0), Tesseract.js (Apache-2.0), WebLLM (Apache-2.0), Lucide (ISC). 선택 모델은 [Qwen3-0.6B MLC](https://huggingface.co/mlc-ai/Qwen3-0.6B-q4f16_1-MLC)입니다. 관련 공식 문서: [PDF.js](https://mozilla.github.io/pdf.js/), [WebLLM](https://webllm.mlc.ai/docs/), [Tesseract.js](https://github.com/naptha/tesseract.js).

`public/sample-policy.pdf`는 기능 검증용으로 직접 만든 **가상 약관**이며 실제 보험사의 약관이 아닙니다. 모든 금액과 조건은 테스트 예시입니다.
